# LexGraph Obsidian Plugin

법률 문서를 그래프, 쟁점 트리, 증거 매트릭스, 당사자 관계도, AI 분석 패널로 함께 다루는 Obsidian 플러그인입니다.

## 주요 기능

- AI 기반 그래프 생성과 로컬 co-occurrence 그래프 fallback
- 노드 드래그, 줌, 패닝, 검색, PNG/JSON 내보내기
- 쟁점 트리, 당사자 관계도, 증거 매트릭스 연동
- 국가법령정보 Open API 기반 법령/판례 조회
- CodeMirror 법률 엔티티 하이라이트
- 폴더 단위 문서 그래프와 문서 간 공통개념 연결
- 그래프 레이아웃, 줌 상태, 수동 증거/사실 입력의 문서별 영속화

## Open API 설정

국가법령정보 Open API는 `OC` request parameter를 사용합니다.

- 설정 경로: `설정 > LexGraph > 국가법령정보 Open API OC`
- 입력값: 이메일 전체가 아니라 이메일 ID 부분
- 예시: `g4c@korea.kr` 이면 `g4c`

참고:

- https://open.law.go.kr/LSO/openApi/guideList.do

## 그래프 상태 저장

다음 상태는 문서 또는 폴더 경로 기준으로 플러그인 데이터에 저장됩니다.

- 그래프 노드 위치
- 줌/패닝 상태
- 수동으로 추가하거나 편집한 증거
- 수동으로 추가하거나 편집한 사실

설정에서 이 기능을 끌 수 있습니다.

- 설정 경로: `설정 > LexGraph > 그래프 상태 저장`

초기화가 필요하면 명령 팔레트에서 다음 명령을 실행하면 됩니다.

- `현재 문서의 저장된 그래프 상태 초기화`

수동으로 추가한 증거와 사실은 `증거` 패널의 목록 탭에서 개별 편집/삭제할 수 있습니다.

## 명령

- `현재 파일의 법률 그래프 열기`
- `쟁점 분석 실행 (로컬)`
- `반박 논거 생성 (로컬)`
- `준비서면 아웃라인 생성 (AI)`
- `현재 분석 결과를 노트로 저장`
- `현재 폴더 전체 법률 분석`
- `현재 문서의 저장된 그래프 상태 초기화`
